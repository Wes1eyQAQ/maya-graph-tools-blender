# 中文使用指南

## 控制器与通道

选择有动画的物体或姿态控制器，在 Graph Editor 顶部开启 Maya 1.26。点击通道即可单独显示并聚焦；Shift/Ctrl 点击可多选。显示全部恢复当前控制器的所有通道；全部通道自动手柄按钮针对列表中的全部通道，不受显示隔离影响。

列表固定八行，可在列表内部使用滚轮或右侧滚动条。三角按钮展开/折叠；搜索支持翻译后的通道名。选择多个控制器后默认只展开第一个，仍可手动展开其他项。

## 直接拖动与框选

按住菱形关键帧拖动，默认只能上下修改数值；按住 Shift 可以自由改变时间与数值。松开确认，Esc 取消。B 框选只选择关键帧，不选择手柄；单击选中某个关键帧后，它的手柄才显示。手柄可以单独点击调整。

## R 编辑框

选中关键帧后按 R。未选中关键帧时先进入只选关键帧的框选。拖动框内部移动，拖动边缘或角点缩放。这里的 Shift 限制为上下方向。Enter 结束；Esc 取消当前这次拖动。

## 上下边界比例是什么？

这是按选区中心分别调整上边界、下边界的功能，100% 代表保持原样，不是透明度或音量。

例如选中数值从 -10 到 +10，中心是 0：下边界 60% 会移到 -6；上边界 80% 会移到 +8。设置后点击应用比例，内部所选数值会随之重新映射。时间宽度 50% 则把所选关键帧时间间距减半，以时间中心为基准。

每次应用以当前选区为基准；连续重复点击会继续缩放，而不是一直回到最初曲线的同一个比例。

## 一键局部循环

1. 先自行匹配首尾姿势或关键帧数值。
2. 选中准备作为首尾的关键帧；中间也选中没关系，时间最早和最晚的位置作为首尾。
3. 需要整理内部切线时开启循环内部自动平滑（Auto Clamped）。
4. 点一键生成循环。

不读取播放起止区间。先寻找各条参与曲线的实际首尾关键帧，再进行判断；任何参与曲线缺少端点或端点重合时，整次操作取消。

只看循环内首帧下一个关键帧、尾帧前一个关键帧的数值高低，不看曲线形状。两侧邻帧都更高：波谷；都更低：波峰。两种情况均把首尾左右手柄设成水平，每个端点的外侧手柄长度与内侧一致。两侧一高一低时匹配首帧右手柄与尾帧左手柄的 Free 斜率，尾帧长度按局部邻帧间距计算。

内部平滑开启时按这个顺序执行：匹配首尾 → 严格位于区间内的手柄设为 Auto Clamped → 重算 → 再匹配首尾。首尾仍为 Free，关键帧数值和选择不变。需要保留内部手调切线时关闭。

## 语言与问号

默认英文，顶部一个按钮循环切换 English → 中文 → 日本語 → English，并记住选择。问号悬停显示说明，点击展开阅读。更新后的旋转球、轴向工具与 F 聚焦插件也共用这个语言设置。

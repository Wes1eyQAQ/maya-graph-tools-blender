# v1.26 — First public release

A practical Graph Editor workflow built through repeated animation tests and fixes.

- Single-click channel isolation and framing on real F-curves.
- Independently scrolling controller/channel list with default multi-controller folding.
- Direct key dragging: vertical by default, Shift for free movement.
- Diamond key markers, triangular handle markers and point-only box selection.
- R region editing and independent lower/upper/time percentages.
- Selection-based local loop matching with peak/trough detection from neighbor key values.
- Optional Auto Clamped interior cleanup, followed by endpoint rematching.
- English default with one-button Chinese/Japanese switching and contextual help.
- Fixes for overlapping-key preservation and stale data references.

Validated on Windows / Blender 4.4.3 / 64-bit. Other versions/platforms need community testing.
